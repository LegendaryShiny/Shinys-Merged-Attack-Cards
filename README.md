# Shiny's Merged Attack Cards

Foundry VTT v14 / dnd5e 6.x

Keeps every attack or ability to a single chat message. Attack rolls, damage rolls and healing rolls made from the activity card are shown inside that card instead of creating separate messages.

## Features

- Attack rolls (including hit/miss on targets) appear inside the activity card
- Damage and healing rolls appear inside the activity card, including the damage application tray
- Multiple attack or damage rolls stack inside the same card
- Deleting the activity card also removes its merged rolls

## Requirements

- The dnd5e client setting "Summarize Chat Cards" must stay enabled (it is by default)
